# 📡 Ayna OTT Live TV Automation & M3U Playlist

> Automated M3U and JSON playlist generator for Ayna OTT live channels, running securely via GitHub Actions.

---

## ✨ Features
* **Auto-Discovery:** Scans Ayna OTT APIs in real-time to fetch active live channels.
* **Multi-Format Support:** Exports channels into clean `ayna_channels.m3u` and `ayna_channels.json` formats.
* **Automated Workflow:** Runs automatically every 1 hour via GitHub Actions.
